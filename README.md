# 🌥️ JustWeather

A minimalist and elegant weather widget for KDE Plasma 6 that displays current weather conditions on your taskbar or desktop using [wttr.in](https://wttr.in/) weather service.

Nothing complicated, just the weather.  
Only weather.  
We love weather.  
Weather..

Also it just made cause the default Plasma weather widget doesn't work with my hometown and I didn't find any simple alternatives.
